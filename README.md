# السلة الذكية — Prototype
هذا نموذج واجهة أولي كامل للواجهة الأمامية:
- بحث موحد
- اختيار المنصات 1688 / Taobao / Pinduoduo
- عرض الأسعار باليوان والدينار الليبي
- سلة مشتريات
- تتبع طلبات (تجريبي)
- تصميم متجاوب للموبايل والكمبيوتر

## التشغيل
افتح index.html مباشرة في المتصفح.

## المرحلة البرمجية التالية
استبدال بيانات products داخل app.js بواجهة Backend حقيقية:
GET /api/search?q=...
GET /api/product/:id
POST /api/orders
GET /api/orders/:code

يجب وضع مفاتيح API والـsecrets في الخادم فقط، وليس داخل JavaScript الخاص بالمتصفح.

## سعر اليوان
الواجهة تحتوي على خانة لتحديث سعر اليوان يدويًا يوميًا. في النسخة التجريبية يُحفظ محليًا؛ في النسخة الحقيقية سينقل إلى إعداد في قاعدة البيانات بحيث يسري على جميع الزبائن.

## لوحة التحكم V5
تمت إضافة لوحة إدارة تجريبية لسعر اليوان، العمولة، وأسعار الشحن حسب التصنيف، مع حفظ الإعدادات محليًا. عند ربط Backend ستصبح هذه الإعدادات مركزية لكل المستخدمين.
